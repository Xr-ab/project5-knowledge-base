        ① 这是干嘛的

        多用户知识库问答系统：上传自己的文档，后台解析入库；提问先查知识库（检索 k=3），文档内查不到就认输不乱编、禁止联网兜底（防幻觉），只有明显是文档外的常识/资讯才转联网；回答逐字流式推给前端。项目6（企业工作空间）的基础版——用它跑通 RAG + 流式 + 评测核心链路。

        目标用户多用户，每人独立的知识库与会话，数据互相隔离
        核心功能文档上传解析（202 异步）· 知识库问答（检索 k=3；文档内查不到禁止联网兜底防幻觉，文档外常识才联网）· NDJSON 流式（打字机 + 状态提示）· 评测脚本
        一句话定位把 RAG、流式、评测这条核心链路吃透，再升级出企业版

        ④ 遇到的问题与解决（9 个）

        ① 183 字回答整段一口吐 streaming 参数
        现象长回答一个分片就整段到达，前端打字机完全失效
        定位对比短问题正常 → 查模型客户端初始化：create_model 没开流式
        修复加 streaming=True。教训：流式链路每层都要显式确认"真的在流"
        ② 开了 streaming 增量还不对 stream_mode
        现象LangGraph 的 messages 流模式拿不到逐 token 增量
        定位61 字短问题压测：updates 模式 334 次回调 / 1.70s——这才是真流式
        修复换 stream_mode="updates"；用"回调次数 + 耗时"两个数字证明效果（0.16s→1.70s）
        ③ 观测上报阻塞主链路 22.2s / 77%
        现象问答总延迟偏高
        定位Langfuse 本地面板瀑布图：上报占 22.2s、总耗时 77%——SDK 的 flush 是同步的
        修复create_task 丢 asyncio 后台；还有第二层坑——后台任务不持引用会被 GC 提前杀掉，用集合 _background_tasks 持引用 + add_done_callback(discard) 自动清
        ④ 前端流式偶尔 JSON.parse 报错 攒半行
        现象流式偶尔前端解析报错
        定位TCP 不按应用层消息边界到达，一行 JSON 可能被切成两半（0.3 行 + 1.7 行）
        修复getReader + TextDecoder，字节先攒 buffer，按 \n 切，完整行才 parse，残行留下一块拼；DevTools Network 里能看到原始流验证
        ⑤ 后台任务报"会话已关闭" 会话生命周期
        现象后台文档处理一跑就报数据库会话已关闭
        定位依赖注入的会话跟着请求走，响应返回就关；后台任务跑在响应之后
        修复后台任务第一行自己开 async_session()，用完自己关——"自己开 · 自己关"
        ⑥ 回写状态时文档可能已被删 并发语义
        现象后台处理完回写状态，文档可能正被用户删除；后台异常没人接，抛了也只剩日志
        修复update_status 查不到就静默跳过而不是抛 404——并发场景下的语义选择："静默跳过才是正确的选择"
        ⑦ 删除文档怎么删干净 删除顺序 + 幂等
        定位删一个文档 = 删两个地方（向量库切片 + 数据库记录），顺序不能反：先向量库后数据库
        修复按 get(where={"document_id"}) 反查切片 id 再批量删；查不到当空操作（幂等）——所以切片 metadata 必带 document_id；删除也要验归属（文档没有 user_id，绕道它挂的会话验）；请求内失败回滚且幂等；临时文件 finally 删
        ⑧ 容器里路径和配置全不对 配置覆盖
        现象容器里 PROJECT_ROOT 向上推 3 层推到 /，数据写丢
        修复环境变量覆盖四件套：DATA_DIR=/app/outputs、DATABASE_HOST=postgres、DATABASE_PORT=5432、LANGFUSE_HOST；配置类 BaseSettings 单一真相源 + 必填缺失早失败 + SecretStr 打码；附带坑：精简镜像没 curl，healthcheck 改标准库 urllib，postgres 用 pg_isready
        ⑨ 上传解析不了 / 连点串台 前端细节
        定位FormData 手动设 Content-Type 会丢 boundary，后端解析不了 multipart；快速连点两会话有竞态
        修复别手动设 Content-Type（浏览器自动生成 boundary）；两层防串台——切会话先 abort() 掐旧流 + selectSeqRef 自增序号，响应对不上号就丢弃
